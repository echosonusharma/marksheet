// how it works

Three steps. Then just click.

01 ——

Install the extension

Load it from the Chrome Web Store or manually via developer mode.

›
02 ——

Connect your sheet

Paste a Google Sheets URL, pick the tab, map columns to URL / title / date.

›
03 ——

Click to save

Hit the extension icon. Current tab appended instantly. Duplicates skipped automatically.

// features

Built for daily use.

▸

One-click save

Click the toolbar icon. URL, title, and timestamp go straight into the sheet row.

▸

Duplicate detection

Already saved this URL? Icon flashes blue and skips the append — no clutter.

▸

Multiple configs

Separate sheets for work, reading, research. Switch active config from the panel.

▸

Flexible column mapping

Map URL, title, and date to any column. Skip fields you don't need.

▸

Works in any Chromium browser

Chrome, Brave, Edge — no browser account required. Just your Google account.

▸

Fast. No loading spinners.

Duplicate checks happen instantly. Nothing waits on a network call before saving.
